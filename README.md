Entry for the [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580)
bounty on make.fun: one line of the worst advice an AI could give, at most
140 characters, written to `/output/entry.txt` by `main.py`.

The line:

> To make your code run faster, delete all the comments — the computer has to read them too.

It was picked from six candidates scored against the judge brief's criteria
in order — worst advice specific enough to follow, funny on the first read,
tight, in a real AI assistant's confident voice, and concrete. It won all
five 1v1 comparisons, and it avoids the field's saturated clichés (microwave
your phone, delete System32, password "password", laptop in ice water).

## Run

```sh
python3 main.py
cat /output/entry.txt
```
